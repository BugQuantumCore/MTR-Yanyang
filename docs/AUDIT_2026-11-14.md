# Rendering and simulation audit — 14 November 2026

## Baseline, method and coverage

- Mod source: `1.21.x`, baseline `effe968c87d9888e249112eda5c9e534815ce798`.
- Transport Simulation Core: `tsc-1.21.x`, baseline
  `41187a103d81139faffdc861a42fd45587544f37`.
- Review branches: `perf/1.21-render-simulation-audit` and
  `fix/tsc-passenger-lifecycle-audit` (pull requests #2 and #1 respectively).
- Local work was restricted to retrieving source, reading, editing and Git diff
  inspection. **No local build, test, benchmark or game launch was performed.**
  All compilation and regression execution is delegated to GitHub Actions.
- GitHub's API was used when Git transport was unavailable. Retrieved source
  blobs and reconstructed base commit/tree objects were checked against their
  Git hashes. Existing unrelated Joban workspaces were not edited.

This is a broad, risk-led source audit with deeper inspection of the paths below.
It is not a proof that every line, asset, dependency or hardware combination is
correct. Vendored Vulkan headers, generated classes and binary assets were not
rewritten. No measured FPS, GPU timing or memory reduction percentage is claimed.

## Implemented findings

### Vulkan, C++ and Rust

1. Preserve the full 64-bit `VkDevice` handle instead of narrowing it to 32 bits.
2. Correct std140 light-vector offsets to 96/112, derive UBO stride from device
   alignment, and filter memory types against `memoryTypeBits`.
3. Set shader entry point `main`; reject failed initialisation and unwind partial
   allocations instead of writing through missing mapped memory.
4. Remove the recursive mutex acquisition during host initialisation and detach
   stale recorder pointers during shutdown.
5. Rebase each material's global OBJ indices into its own vertex buffer. Supply
   the actual group-filter length; previously group builds could copy the whole
   model. Preserve winding for a 180-degree Y rotation and retain nested-instance
   mesh ownership.
6. Use one native placement per whole-model transformation and select its matching
   material mesh. This removes the N-material/N-squared mesh duplication.
7. Reuse frame snapshot storage, descriptor lookup storage, equal-pose matrix
   calculations and consecutive mesh bindings. No GPU performance measurement is
   implied by these eliminated operations.
8. Validate queue pointers/capacities against mapping lengths, avoid integer
   overflow in record sizes, and reject oversized results.
9. Make Rust regression checks actually fail their test instead of only printing
   failures. Update Windows system-library linkage required by the Rust runtime.

### Renderer integration

10. Keep native command recording on the render thread with synchronous JNI
    (JDK 21+) or the corrected FFM descriptor API (JDK 22+). The asynchronous
    poller only handles build work; a timeout no longer lets two threads record
    into the same command buffer.
11. Borrow the host's existing GPU images/views/samplers for all textures. Remove
    duplicate decoding/staging/upload and illegal transfers in the active pass.
12. Inherit host viewport/scissor and invalidate its pipeline-binding cache after
    native recording, without resetting host descriptor pools.
13. Advance the transport handshake to v3 so incompatible old native binaries
    cannot silently ignore the new ownership flags or texture-table budget.
14. Route Radiance models through its captured `RenderType.draw(MeshData)` path,
    batching model/stage instances with transformed positions/normals and lighting.
    Bind/unbind VBOs explicitly on the OpenGL path and restore shader colour.
15. Publish asynchronous model completion with a volatile flag.

### Collision, passengers and path work

16. Publish collision snapshots when entries move or are inserted; the original
    non-empty snapshot could remain frozen until an expiry deletion.
17. Sample velocity at high frame rates using monotonic time and a time-based
    blend. Preserve the complete `(vehicleId, carNumber)` key.
18. Remove obsolete hulls on boarding/empty geometry. Reuse stationary entries
    and lazily cached VoxelShapes.
19. Compute rotated AABBs from a shared rotation matrix and half extents instead
    of constructing every corner and repeating trigonometry for every box.
20. Correct containment exit distances and enforce the collision fallback's
    movement budget across the whole move, including multiple resolution passes.
21. Use complete passenger-ground-cache keys, reuse block-state/position scratch,
    cache empty standing results, correct the wandering direction sample,
    rebake passenger models after resource reload, and release world references
    on disconnect.
22. Immediately complete rejected path tickets with fallback and remove failed
    cached tickets so later requests can retry. Preserve access-order eviction.
23. In TSC, include the first carriage and coupling intervals in boarding choice,
    reject invalid consist lengths, invalidate removed vehicles, and synchronise
    same-route journey-leg consumption.
24. Cover the complete walking-transfer radius across grid boundaries; compute
    platform midpoints once per graph/CSA operation instead of per candidate pair
    or request.

### Textures, caches, packets and verification

25. Reject/retry full generation queues without losing accepted tasks. Bound
    pending texture requests and per-frame uploads; move cropping to the worker,
    close source images, discard stale reload/session results, and retain the
    previous texture while refreshing.
26. Cache system-font enumeration and fallback glyph lookups; handle complete
    Unicode code points. Include all colour inputs in texture keys and limit
    expiry scans to four per second.
27. Honour worker interruption, clear its liveness reference in `finally`, and
    reject submissions after shutdown.
28. Protect arrival-cache lists from caller mutation, clear server-world caches
    between sessions, and replace per-pixel `Color` allocations with ARGB shifts.
29. Send only occupied packet bytes, preserve primitive boundaries and embedded
    NULs, release Netty buffers, avoid recursive/O(N²) chunk scheduling, isolate
    incomplete packets by peer, and enforce assembly/count/allocation bounds.
30. Validate ticket purchase options and available emeralds on the server before
    granting credit. Reject forwarded request endpoints that could change the
    configured loopback authority. Rider identity validation is implemented at
    the request boundary; this does not establish a complete driving permission model.
31. Make PR CI check out the triggering revision, include tests in native workflow
    path filters, pin the audited TSC revision and run its tests before consuming
    it. Add Minecraft dependencies to the NeoForge test source set.
32. Preserve TSC's `settings.gradle.kts` so CI actually includes `path-computation`.
    Test shutdown using the pool's own threads and bounded joins rather than a
    racy global thread-name scan. Do not rewrite model assets from validation
    tests or swallow file-read failures.

## Evidence and validation

The accompanying tests cover collision snapshots/keys/containment, rotated AABB
parity, path saturation and retry, boarding/lifecycle/walking boundaries, packet
round trips and malformed input, texture queue backpressure, cache ownership,
native placement, shared-memory layout and FFM calls. Native suites cover the
recorder and actual domain-to-mesh integration. The Actions matrix builds
1.21.1/1.21.4 on Fabric and NeoForge, native Windows/Linux x64/ARM64, macOS ARM64,
and Android/iOS cross targets; iPadOS uses the verified iOS binary copy.

Initial GitHub execution exposed Windows linkage, stale Rust layout assertions,
NeoForge test-classpath omissions and a thread-termination test race. Those were
addressed from runner logs, not by running local builds. The final PR checks and
workflow run identifiers are the authority for pass/fail and artifact provenance.

Source contracts were cross-checked against Radiance `main`
`948b29a35328ee812b9aa566fc8de2789100291a`, VulkanMod `0.6.6`
`67e20f1f359a3a0611e2312a8a72e47fc9a09737` and `1.21`
`3adda56191e1a09ce3155de33f8d8334482e089f`, OpenJDK `jdk-25-ga`
`6c48f4ed707bf0b15f9b6098de30db8aae6fa40f`, and ModDevGradle's source-set API.
These source checks are not runtime compatibility certificates.

## Remaining work and acceptance measurements

- **Game/hardware validation:** compare OpenGL, VulkanMod, Beryl on/off and
  Radiance using the same world/camera/resource pack. Check doors, transparent
  interiors, lit materials, animated/PIDS textures, pack reload, disconnect and
  backend transitions. Collect CPU frame-time p50/p95/p99, GPU timestamps,
  allocation rate, native/VRAM growth, draw counts and uploaded bytes.
- **GPU lifetime:** replace the descriptor/UBO rotation heuristic with explicit
  host fence/frame-slot ownership before supporting more submission patterns.
  Keep the internal native texture uploader disabled until a separate transfer
  phase is available. Device-idle mesh retirement is safe but can still stall.
- **Geometry:** conservative world AABBs remain; this does not implement exact
  rotated OBB collision, sloped floor height, continuous collision detection or
  full navigation over stairs. Validate diagonal doorways and high-speed motion.
- **Native colour/fallback:** the 24-byte upload format lacks per-vertex colour.
  Runtime failure and shader-backend switches must reliably rebuild native-only
  resources before expecting the Java path to draw them.
- **Simulation:** same-ID vehicle object replacement needs a defined occupant
  migration policy. Collision and AI should remain CPU-authoritative until
  profiling justifies a deterministic asynchronous GPU design; headless servers
  must remain supported.
- **Memory/I/O:** the resource text cache is cleared on reload but has no byte
  budget within a pack. File-cache reads/writes remain synchronous. Large texture
  resolution settings need a byte-based budget as well as item-count limits.
- **Permissions:** chunk and rider-identity bounds are not a complete server
  authorisation policy. Remote block-entity edits, driving rights/keys/proximity,
  generic operation packets and local HTTP endpoint allowlists need a coordinated
  permission design that preserves intended server workflows.
- **Scope:** incidental UI/website/schema and third-party behaviour was not
  exhaustively executed. Keep reviewing these modules independently; neither
  static review nor green CI proves that all repository code is defect-free.
